# Photographs

## `manual/` — Centronics GLP Users Manual, `37403101-9A00` Rev A, October 1984

This manual is not online anywhere. The only catalogued copy is at Stanford, unscanned and
uncatalogued for text. These are photographs of a physical copy, published so the switch
tables in the main README can be checked rather than taken on trust.

| File | What it shows |
|------|---------------|
| `cover.jpg` | Manual cover |
| `title-page.jpg` | Part number, revision and date |
| `dip-switches-pages-2-10-2-11.jpg` | Section 2.8, the DIP switch pages as a spread |
| `table-2-1-sw2.jpg` | **Table 2-1** — DIP SW2, parallel and serial |
| `table-2-2-sw1-and-2-3-baud.jpg` | **Table 2-2** — DIP SW1 (serial) and **Table 2-3** baud rates. Also the BUSY polarity paragraph. |
| `figure-1-4-switch-segments.jpg` | **Figure 1-4** — segments run 8..1 left to right within each block |
| `dip-switch-location-handwritten-correction.jpg` | Block location figure, carrying a previous owner's **handwritten correction** to the numbering |
| `appendix-b-parallel-pinout.jpg` | Appendix B section 1, parallel (Centronics) pin assignment |

**Not photographed:** Appendix B section 2, the **serial** pin assignment. That gap was
closed by measurement instead — see §3 of the main README.
